# Receitinhas Web

Projeto final do PI.

Tecnologias: Java 17, Spring MVC, Thymeleaf, JDBC, MySQL, JUnit 5, Maven e NetBeans.

Funcionalidades: cadastro de usuário, login, cadastro de receitas, listagem e filtro por tipo.

1. Execute o arquivo database.sql no MySQL.
2. Confira usuário e senha do MySQL em src/main/resources/application.properties.
3. Abra a pasta no NetBeans como projeto Maven.
4. Execute com a classe com.receitinhas.ReceitinhasApplication.
5. Acesse http://localhost:8080/login.

Os testes ficam em src/test/java.


Etapa final do projeto integrador.
